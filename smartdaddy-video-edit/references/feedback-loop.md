# 피드백 루프: 스킬을 내 편집자로 키우는 법

이 스킬의 진짜 가치는 처음 들어 있는 규칙이 아니라 **쓸수록 쌓이는 `내 규칙`**이다. 같은 지적을 두 번 하지 않는 게 목표다.

## 사람이 피드백을 줄 때 (사용자에게 안내할 것)

1. **처음부터 긴 영상을 맡기지 않는다.** 1분짜리, 또는 긴 영상의 훅(첫 30초)부터 시작한다.
2. **"몇 초에 뭐가 어떻다"로 구체적으로 말한다.**
   - 좋음: "1:27, 더 빨리 가는 효과를 넣어 줘. 바람 같은 거", "5:43, 이 캐릭터 줌인해서 강조"
   - 아쉬움: "좀 더 재밌게", "뭔가 심심해"
3. **한 번에 한 요소만 판다.** 효과음이 마음에 안 들면 같은 장면으로 효과음만 여러 번 바꿔 보며 고른다. 다른 요소까지 한꺼번에 바꾸면 무엇이 좋았는지 알 수 없다.
4. **싫으면 빼라고, 크면 줄이라고 직접 말한다.**
5. **회차가 끝나면 "이번에 배운 거 스킬에 저장해 줘"라고 한다.** 이 한마디가 제일 중요하다.

## Codex가 규칙을 저장할 때

1. 이번 회차 피드백 중 **이 영상에만 해당하는 것**(이 장면의 이 문구)과 **다음 영상에도 해당하는 것**(자막은 언제나 0.2초 늦게)을 나눈다. 뒤의 것만 저장한다.
2. `references/rules.md` 맨 아래 `내 규칙`에 추가한다.
   ```
   - [날짜] 규칙 한 줄. 가능한 한 숫자로.
     왜: 사용자가 한 말 그대로 (어느 영상 몇 초)
   ```
3. **이미 비슷한 규칙이 있으면 새 줄을 쓰지 않고 그 줄을 고친다.** 그래서 앞뒤가 맞지 않는 규칙이 두 개 생기지 않게 한다.
4. 위쪽 기본 규칙과 부딪히면 `내 규칙`이 우선이다. 부딪힌다는 사실을 사용자에게 한 줄로 알린다.
5. 추가하거나 고친 줄을 사용자에게 그대로 보여 준다.

## 좋은 규칙과 나쁜 규칙

| 나쁜 규칙 | 좋은 규칙 |
|---|---|
| 효과음은 적게 | 본편 효과음은 1분에 보통 1~2개, 많아도 5개. 모션 요소가 뜰 때마다 넣지 않는다 |
| 반복 좀 잘 잘라 | 같은 말을 반복하면 항상 앞의 것을 자르고 마지막 것만 남긴다 |
| 자막 타이밍 잘 맞추기 | 자막 시작은 목소리 시작 + 0.15초, 끝은 말 끝 + 0.2초 |
| 인트로를 멋지게 | 인트로는 실제 영상으로 채우고 모션은 얹기만. 가짜 댓글·가짜 차트 금지 |
| 줌을 적당히 | 줌은 한 장면에 한 번. 말로 가리킨 UI만 |

**숫자가 없는 규칙은 지켜지지 않는다.** 실제로 "효과음은 적게"라는 규칙이 저장돼 있었는데도 15초에 효과음 12개를 넣었다. 분당 개수로 바꾼 뒤부터 지켜졌다.

## 정리 주기

`내 규칙`이 30줄을 넘으면, 또는 사용자가 "규칙 정리해 줘"라고 하면:
- 비슷한 규칙을 합친다.
- 더 이상 맞지 않는 규칙(사용자가 취향을 바꾼 것)은 지우고 사용자에게 알린다.
- 자주 쓰는 규칙은 위쪽 기본 규칙의 알맞은 장으로 옮긴다.

## 실제 사례: 영상 한 편에서 나온 피드백

12분짜리 대결 영상 하나를 편집하는 동안 사람이 보낸 수정 요청은 47개였다.

| 분야 | 개수 | 예 |
|---|---|---|
| 모션그래픽 | 14 | 점수판, 라운드 전환, 인트로, 숫자 롤업 |
| 줌·하이라이트 | 13 | 조절판 하이라이트, 캐릭터 줌, 승자 하이라이트 |
| 구성 | 7 | 결과물을 크게, 덮어씌우기, 인트로를 실제 영상 위주로 |
| 효과음 | 6 | 너무 많음, 다닥다닥, 띠링 |
| 자막·텍스트 | 4 | 가운데 '쾅', 의미 단위, 0.15초 늦추기 |
| 기타 | 3 | 재생 끊김 |
| 컷 | 0 | 컷은 사람이 CapCut에서 직접 잘랐다 |

이 피드백이 위 기본 규칙의 상당 부분이 됐다. 다음 영상에서는 같은 요청이 크게 줄었다.
