# 모션 카드

라운드 카드, 숫자 굴리기, 단계 목록, 판정표, 점수판, 좌우 비교처럼 **말로 길게 설명할 것을 한 화면으로 보여 주는 짧은 영상**이다. 템플릿 하나(`motion/cards.html`)에 여섯 종류가 들어 있고, 값만 넘겨 `scripts/render_motion.py`로 렌더한다. 모션 프로그램은 필요 없다.

## 원칙

1. **실제 화면이 주인공이다.** 모션만 이어지면 강의 영상이나 AI가 찍어 낸 영상처럼 보인다. 녹화 화면, 작업 화면, 완성본 컷 사이에 2~10초짜리 카드로만 넣는다.
2. **덮어 얹는다.** CapCut에서 원래 화면 위 트랙에 올린다. 사이에 끼워 넣지 않으니 영상 길이가 늘지 않고, 지우면 원래 화면이 나온다.
3. **말과 맞춘다.** 칸이 켜지는 시각, 숫자가 굴러가기 시작하는 시각은 대본이 아니라 **실제 녹음 받아쓰기의 낱말 시각**으로 정한다. 카드 안 시각 = 낱말 시각 − 카드를 얹는 시각. 대본의 '삼십 시간'과 받아쓰기의 '30시간'처럼 철자가 다를 수 있으니 받아쓰기에서 찾는다.
4. **숫자는 말하는 순간 0부터 굴린다.** 약 1.2초, 끝에서 부드럽게 멈춘다. 멈추는 순간에 효과음을 맞춘다.
5. **숫자는 실제 값만 쓴다.** 꾸민 숫자, 반올림해 부풀린 숫자는 넣지 않는다. 10만 직전이면 95,000 → 100,000처럼 쓴다.
6. **전환을 섞는다.** 같은 등장이 계속 나오면 질린다. 종류마다 등장 방식이 다르고, 같은 카드를 여러 번 쓰면(라운드 카드 등) `in=`으로 회차마다 바꾼다. 쾅 하고 터지는 효과, 파티클, 충격파 고리, 통통 튀는 움직임은 쓰지 않는다. 큰 강조는 카드 하나에 한 번이다.
7. **한 화면에 한 생각.** 정보를 한꺼번에 작게 깔면 PPT처럼 보이고 휴대폰에서 안 읽힌다. 항목이 여러 개면 말하는 순서대로 하나씩 켠다.
8. **끝 0.5초는 완전히 멈춘다.** CapCut에서 길이를 늘려 쓸 수 있게.

## 스타일 (템플릿에 들어 있는 값)

```
바탕   거의 검정 #07080B + 은은한 빛 두 개(주황 왼쪽 위, 청록 오른쪽 아래) + 64px 격자 3% + 가장자리 어둡게 + 옅은 그레인
       화면 전체가 카드 길이 동안 천천히 2% 다가간다
색     주황 #FF8A5B = 지금 켜진 것·우리 쪽,  민트 #3EE6C8 = 무료·된다. 나머지는 흰색과 회색. 노란 글자는 쓰지 않는다
강조   색 글자로 강조하지 않는다(촌스럽다). 강조 낱말은 [대괄호] → 흰 상자 + 검은 글자, -2.5도 기울인 스티커
글꼴   Pretendard 하나, 굵기로 위계. 제목 Bold, 본문 Medium, 라벨 SemiBold에 자간 넓게, 큰 숫자 Light
카드   반투명 어두운 유리, 1.5px 옅은 테두리, 모서리 22px, 깊은 그림자
크기   1920 폭 기준 제목 38px 이상, 본문 40px 이상, 핵심 숫자 120px 이상. 넘치면 템플릿이 글자를 줄인다
등장   흐림 → 선명 + 위로 28px, 0.6초, 여러 개면 70ms 간격. 그 밖에 한 글자씩, 쓸어 열기, 밀려 들어오기, 일어서기
켜짐   주황 테두리 + 바깥 빛 + 3.5% 커짐. 다음 칸이 켜지면 꺼진다(한 번에 한 칸). 아직 안 나온 칸은 이름을 흐리게 가린다
```

## 종류

| kind | 언제 | 길이 | 등장 |
|---|---|---|---|
| `title` | 새 단락·라운드 시작. 작은 라벨 + 큰 제목 + 의미 한 줄 | 2.4~3초 | 한 글자씩(기본), `in=`으로 바꿈 |
| `number` | "30시간 → 8시간", "효과음 59개 → 17개" | 3~4초 | 흐림에서 다가옴 + 막대 쓸어 열기 |
| `steps` | 편집팀 8칸, 오늘 할 일처럼 3~8개를 하나씩 말할 때 | 항목 수 × 0.8초 이상 | 칸이 차례로 떠오르고 말에 맞춰 한 칸씩 켜짐 |
| `verdict` | "AI가 됩니다 / 아직 사람 몫" 정리 | 5~8초 | 제목 쓸어 열기 + 항목이 옆에서 밀려 들어옴 |
| `score` | 라운드 판정 직후 점수판(2~3명) | 2.6~3.2초 | 카드가 일어서고 이긴 쪽 점수가 +1 |
| `compare` | "클로드 초벌 vs 최종"처럼 둘을 나란히 | 3~5초 | 가운데에서 양쪽으로 열림, 카메라는 고정 |

키 목록과 복사해 쓰는 명령은 `motion/examples.md`에 있다.

## 만드는 법

아래 명령의 `scripts/`와 `motion/` 입력은 스킬 폴더의 절대 경로, `편집/` 출력은 영상 작업 폴더의 절대 경로로 바꿔 실행한다. 작업 폴더가 스킬 폴더와 같다고 가정하지 않는다.

Windows Codex 격리 환경에서는 Playwright 드라이버 실행이 멈출 수 있다. `render_motion.py`는 시작을 기본 20초(`--startup-timeout`으로 변경 가능)까지 감시하고 멈춘 프로세스를 종료한 뒤 오류를 표시한다. 이 경우 브라우저 파일 유무와 `playwright` 패키지를 확인하고 승인된 일반 사용자 환경에서 렌더한다. 렌더러는 실제 사용자 홈의 Playwright 브라우저 캐시를 찾는다.

1. 받아쓰기에서 카드가 붙을 대사와 낱말 시각을 찾는다. 카드를 얹을 시각과 항목별 `at`을 정한다.
2. 값을 넘겨 몇 장면만 PNG로 본다:
   ```
   python scripts/render_motion.py motion/cards.html 편집/motion/check --dur 4 --frames 0.5,1.5,3.5 --query "kind=number&title=편집 시간&from=30&to=8&unit=시간"
   ```
   글자가 넘치지 않는지, 한국어가 제대로 나오는지, 칸이 한 번에 하나씩 켜지는지, 마지막이 멈춰 있는지 본다.
3. 괜찮으면 영상으로 렌더한다(`--frames`를 빼고 mp4 경로를 준다). 1920×1080, 30fps.
4. CapCut 프로젝트의 덮개 트랙에 얹는다.

값 넘기는 규칙:
- 한글·띄어쓰기·JSON은 그대로 쓴다. render_motion.py가 주소에 맞게 바꿔 준다. 값 안의 `&`만 `%26`으로 쓴다.
- 목록은 `|`로 나누거나(`items=감독|편집자`), `data={JSON}`으로 넘긴다. PowerShell에서는 JSON 안을 작은따옴표로 써도 된다.
- 값이 잘못되면 카드 자리에 "카드 오류" 화면이 나오고, render_motion.py가 끝에 `HTML 오류:`로 이유를 알려 준다.
- 같은 `t`에는 항상 같은 그림이 나온다. 무작위 값과 실제 시계를 쓰지 않는다. 새 종류를 덧붙일 때도 이 규칙을 지킨다.

## 글꼴

Pretendard는 무료(OFL) 글꼴이다. 글꼴 파일은 이 스킬에 넣지 않았다. cards.html은 다음 순서로 찾는다.

1. 컴퓨터에 설치된 Pretendard
2. cards.html 옆 `fonts/` 폴더의 파일(`Pretendard-Light.otf`, `-Regular`, `-Medium`, `-SemiBold`, `-Bold`, 또는 `.woff2`, `PretendardVariable.woff2`)
3. 맑은 고딕 → Apple SD 고딕

설치했는데도 크로미움이 못 찾을 때가 있다(현재 사용자용으로만 설치했거나, 글꼴 폴더에 파일만 복사하고 등록하지 않은 경우). PNG에서 큰 숫자가 얇은 Light로 안 보이면 대체 글꼴이 쓰인 것이니, Pretendard 파일을 `motion/fonts/`에 복사하고 다시 렌더한다.
