# instar_reels 자막 모션

이 스킬은 자동 편집 결과의 텍스트 스타일과 발화 싱크에 적용한다. 사용자 영상과 대본, 현재 저장된 편집 결과를 먼저 확인한다. [디자인 기준](references/style.md)과 프로젝트 루트의 `config/caption_style.json`을 사용한다. 참고 이미지·미리보기 영상이 작업 폴더에 있으면 시각 검토에 쓰되, 문구와 좌표는 새 영상에 맞춰 바꾼다.

이 프로젝트의 기본 나레이션 재생 속도는 **속도 변경 전 원본 음성의 1.25배**다. 다른 속도를 요청받으면 그 값을 따른다. 이미 배속한 파일을 다시 배속하지 않는다. 영상 컷만 바뀌는 지점에서는 음성 트랙을 연속으로 유지한다. 음성을 분할해야 한다면 실제 무음과 첫 음절을 듣고 확인하며, `words.json`의 구간 경계를 그대로 자르기 지점으로 사용하지 않는다. 배속 후 낱말 시각을 다시 맞춘 뒤 자막을 렌더한다.

이 프로젝트의 기존 복제 목소리는 루트의 `elevenlabs_voice.json`에서 찾는다. 별도 지시가 없으면 기존 ID를 재사용하고 화면·대본 표기는 `윤소연 원장`으로 통일한다. 엔딩 로고 이미지는 루트의 `로고/`에서 찾고, 없으면 확인된 `COSMICO` 표기의 텍스트 워드마크로 자동 진행한다.

## 기존 파이프라인에 연결

1. `scripts/elevenlabs_reels.py`는 `words.json`, `cues.json`, `captions.srt`를 만든다. 새 스타일이나 재생 속도 변경 때문에 음성을 다시 생성하지 않는다. 음성을 1.25배속으로 처리했다면 자막 시각도 1/1.25로 변환하고 앞 여유 시간을 반영한다.
2. `scripts/render_reel.py`의 `write_ass`가 자막을 MP4에 그린다. 현재 코드는 `cues.json`의 문구를 Malgun Gothic 스타일로 렌더한다. 스타일 적용 작업이라면 `words.json`도 읽어 `write_ass`에 전달하고, 문구의 핵심 낱말이 실제 발화할 때만 커지도록 텍스트 이벤트를 만든다. 기본 자막의 의미 단위는 `cues.json`을 유지한다.
3. `--motion-titles`를 켠 경우 실제 대본의 장면 제목을 사용한다. 제목이 길면 의미 단위로 나누고 둘째 행과 이어지는 행에 다른 색·등장 효과를 준다. 대본에 없는 사실이나 메시지를 제목으로 만들지 않는다.
4. `config/caption_style.json`의 내용 또는 스타일 버전을 렌더 캐시 키에 포함한다. 그래야 스타일만 바꾼 경우에도 새 결과가 렌더된다.
5. 처음에는 기존 `편집/elevenlabs/` 결과의 5초 사본을 만들어 음성 싱크, 가독성, 피사체 가림을 검수한다. 그다음 전체 렌더에 적용한다. 기존 MP4와 원본 클립을 덮어쓰지 않는다.

`SKILL.md`와 JSON은 편집기에게 주는 지침·설정이다. 자동 생성 영상에 효과를 실제로 넣으려면 `render_reel.py`가 이를 읽도록 연결해야 한다.
