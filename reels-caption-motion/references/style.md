# 자막 스타일 기준

- 모든 한글 글꼴은 Paperlogy 계열. 기본 글자는 7Bold, 의미상 핵심 낱말 1~2개만 9Black. 설치 경로는 실행 환경에서 찾는다.
- 두 번째 큰 제목 행은 이전 기준 대비 10% 확대, 글자색 `#F14951`, 화이트 윤곽선과 가는 어두운 바깥 경계. 프레임 너비의 90%에 닿기 전에 의미 단위로 분리한다.
- 긴 두 번째 행의 다음 줄은 같은 글꼴 계열을 유지하면서 크기 80~90%, 어두운 글자·흰 윤곽선과 0.1~0.4초의 짧은 페이드 또는 와이프로 구별한다.
- 아래 자막은 최종 음성의 발화 시작 시각에 맞춰 낱말을 나타낸다. 기본 1.25배속을 적용한 경우 원본 `words.json`을 그대로 사용하지 않고 새 음성에 맞게 시간을 변환한다. 핵심 낱말은 주변보다 20~30% 크고 더 굵게 한다. 타임스탬프와 실제 소리가 다르면 음성을 듣고 보정한다.
- 작은 흰 텍스트 박스는 글자에 맞는 크기로만 쓴다. 인물, 제품, 손동작, UI, 이미 영상에 들어간 중요한 메시지를 지속적으로 가리지 않는다. 제목과 자막이 차지하는 높이 합계는 약 25% 이내를 목표로 하고, 빈 공간이 없으면 제목이나 장식을 줄인다.
- 등장 모션은 짧은 페이드와 4~10px 정도의 이동으로 제한한다. 단어마다 큰 바운스를 반복하지 않는다. 하단 강조는 해당 단어를 말할 때 시작한다.
- 참고 이미지의 문구·좌표를 다른 영상에 고정 적용하지 않는다. 매 영상의 피사체 위치, 원본 자막, 화면 밝기를 확인한다.
