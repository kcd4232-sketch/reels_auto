# 작업 보드 테마

사용자가 선택한 **Light Green**(Alexander VQ)의 어두운 테마를 적용합니다.

- 원본: https://tweakcn.com/themes/cmlhfpjhw000004l4f4ax3m7z
- 가져온 토큰: `../config/dashboard_theme.json`
- 화면 스타일: `app.css`

원본의 OKLCH 색상, 1rem 카드 모서리, 색상을 사용하고 카드 깊이는 얇은 경계선으로 표현합니다. 기본 HTML·CSS 보드이므로 shadcn 설치 없이 CSS 변수로 연결했습니다. 글꼴은 Inter가 설치되어 있으면 사용하고, 없으면 한국어를 지원하는 시스템 글꼴로 표시합니다. 작은 글씨의 가독성을 위해 본문 자간을 좁히지 않고 보조 글씨를 12px 이상으로 맞췄습니다.

라임색은 실행 버튼과 진행률에 사용하며, 버튼 글자는 원본의 검정색을 사용합니다. 링크·키보드 포커스는 원본의 라이트 그린으로 표시합니다. 경고·오류는 구분 가능한 의미 색상을 유지합니다. 첨부 레퍼런스에 맞춰 어두운 모드를 고정합니다. 배경은 거의 검정인 네이비, 카드는 한 단계 밝은 네이비, 보조 버튼은 슬레이트색입니다. 입력창은 #141d2e이며 오류·경고도 어두운 바탕에 밝은 글씨로 표시합니다.
